1 Struktur File & Koneksi Otomatis CSS / JavaScript

Editor ini secara otomatis menghubungkan semua file .css dan .js yang ada di folder tema. Anda tidak perlu menambahkan tag <link> atau <script> manual di index.html.

Struktur folder tema:

media/
└── templates_html/
    └── {% templatetag openvariable %} theme.slug {% templatetag closevariable %}/
        ├── index.html          ← HTML utama (tab HTML)
        ├── style1.css          ← CSS pertama (tab CSS)
        ├── style2.css          ← CSS kedua (opsional)
        ├── script1.js          ← JS pertama (tab JavaScript)
        ├── script2.js          ← JS kedua (opsional)
        └── images/             ← Folder semua gambar tema
  • Semua file style*.css akan disuntik otomatis ke dalam tag <style> di bagian <head>.
  • Semua file script*.js akan disuntik otomatis ke sebelum tag </body>.
  • Urutan file ditentukan oleh angka di nama file (style1.css, style2.css, ...).

2 Cara Menggunakan Editor (HTML, CSS, JavaScript)

  1. Tab HTML: edit seluruh konten undangan di index.html. Di sinilah Anda menaruh struktur HTML dan kode Django template.
  2. Tab CSS:
    • Pilih file dari dropdown (misalnya style1.css, style2.css).
    • Gunakan tombol Add CSS untuk meng-upload file baru. File baru otomatis menjadi styleN.css.
  3. Tab JavaScript:
    • Pilih file dari dropdown (misalnya script1.js, script2.js).
    • Gunakan tombol Add JS untuk meng-upload file baru. File baru otomatis menjadi scriptN.js.
  4. Save All: menyimpan index.html, semua CSS, dan semua JS sekaligus. File akan dinormalisasi menjadi style1.css, style2.css, script1.js, dst.
  5. Validate: mengecek variabel Django yang digunakan di HTML (apakah sesuai daftar variabel yang tersedia).

3 Cara Menggunakan Gambar (Tab Images)

  1. Buka tab Images di editor.
  2. Gunakan tombol Upload untuk menambahkan satu atau beberapa gambar ke folder images/.
  3. Setelah upload, setiap kartu gambar memiliki:
    • Copy Code: menyalin kode <img> siap pakai.
    • Delete: menghapus file dari folder images/.

Contoh pemakaian di HTML:

<!-- Contoh 1: Gambar langsung -->
<img src="/media/templates_html/{% templatetag openvariable %} theme.slug {% templatetag closevariable %}/images/hero.jpg" alt="Hero">

<!-- Contoh 2: Gambar sebagai background section -->
<section style="background-image: url('/media/templates_html/{% templatetag openvariable %} theme.slug {% templatetag closevariable %}/images/background.jpg');">
    ...
</section>

Tip: lebih mudah gunakan tombol Copy Code di tab Images, lalu paste ke editor HTML.

4 Variabel Django yang Bisa Dipakai di Template

Berikut ringkasan variabel yang bisa dipakai di index.html. Daftar lengkap bisa dibuka juga dari tombol Variables di editor.

Contoh dasar:

<!-- Nama mempelai -->
<h1>{% templatetag openvariable %} groom.full_name {% templatetag closevariable %} & {% templatetag openvariable %} bride.full_name {% templatetag closevariable %}</h1>

<!-- Tanggal acara akad -->
<p>Akad: {% templatetag openvariable %} event.akad.event_date {% templatetag closevariable %} pukul {% templatetag openvariable %} event.akad.start_time {% templatetag closevariable %}</p>

<!-- Alamat venue -->
<p>Lokasi: {% templatetag openvariable %} event.akad.venue_name {% templatetag closevariable %} - {% templatetag openvariable %} event.akad.venue_address {% templatetag closevariable %}</p>

Loop gallery, story & wishes:

<!-- Galeri foto -->
{% templatetag openblock %} for photo in photo_gallery {% templatetag closeblock %}
    <img src="{% templatetag openvariable %} photo.image.url {% templatetag closevariable %}" alt="{% templatetag openvariable %} photo.caption {% templatetag closevariable %}">
{% templatetag openblock %} endfor {% templatetag closeblock %}

<!-- Love story timeline -->
{% templatetag openblock %} for story in love_stories {% templatetag closeblock %}
    <div class="story-item">
        <h3>{% templatetag openvariable %} story.title {% templatetag closevariable %}</h3>
        <p>{% templatetag openvariable %} story.date {% templatetag closevariable %}</p>
        <p>{% templatetag openvariable %} story.description {% templatetag closevariable %}</p>
    </div>
{% templatetag openblock %} endfor {% templatetag closeblock %}

<!-- Wedding Wishes -->
<div id="wishes_wrapper">
    {% templatetag openblock %} if wishes {% templatetag closeblock %}
        {% templatetag openblock %} for wish in wishes {% templatetag closeblock %}

            <p>{% templatetag openvariable %} wish.address {% templatetag closevariable %}</p>
            {% templatetag openblock %} endif {% templatetag closeblock %}
            <p>{% templatetag openvariable %} wish.comment {% templatetag closevariable %}</p>

            <img src="{% templatetag openvariable %} wish.image {% templatetag closevariable %}" alt="{% templatetag openvariable %} wish.name {% templatetag closevariable %}">
            {% templatetag openblock %} endif {% templatetag closeblock %}

</div>
